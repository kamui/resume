## Big Fuel Communications LLC — Software Engineer

`March 2011 - June 2012 · New York, NY`

Created a Social Media Management System for building and deploying Facebook pages and tabs, in Ruby on Rails and MongoDB. The platform was a single Rails application containing reusable components: surveys, polls, signups, image submissions, image galleries and asset downloads.

Facebook tabs could be built quickly from the available components, which were then managed through an admin console. Each tab was essentially a single git repository. Pages were written in any language supported by Tilt (Haml, Sass, CoffeeScript, Slim), and assets used the Rails asset pipeline with Sprockets.

Building pages was deliberately not dumbed down into a drag-and-drop GUI. The idea was to let a developer build anything by hand-coding the HTML, CSS and Ruby, with helpers available to drop in the reusable components.

Tab versions could be scheduled and deployed automatically. The platform server pulled the specified git repo and branch or tag at the scheduled date, compiled assets, uploaded them to S3, then updated the internal cache to reflect the new page.

# Notes before you paste

**Formatting.** LinkedIn does not render Markdown. The `•` characters and line
breaks above paste through fine, but any `**bold**` will show up as literal
asterisks. The bold in this file is only in the headers and the Education block,
which you would not be pasting into a description field anyway.

**Blank lines between bullets.** LinkedIn collapses some whitespace depending on
where you paste from. If the bullets come out cramped, paste into a plain text
editor first, then copy from there.

**Three descriptions run close to the limit.** Away (1,977), Modern Age (1,955)
and International Masters Publishers (1,912), against a 2,000 cap. If LinkedIn
rejects any of them, drop the last bullet. In all three cases the final bullet
is the most general and the least missed.

**Company descriptions.** The opening paragraph of each job holds the scope
detail: who you reported to, team size, budget. LinkedIn has no separate field
for this, so it needs to live in the description. It is the single most
valuable thing in this document and it was missing from your old profile
entirely.

**The Fête pivot note.** Worth keeping. A seven-month stint at the top of a
profile with no explanation invites the least generous guess.

**Away and Legacy revenue figures are deliberately absent.** Legacy is under
NDA. Away you flagged as possibly under NDA. Headcount and budget carry the
scope without the risk.
